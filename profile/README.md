# Gizlet

Gizlet turns handheld game consoles into pocket Linux computers. Install Gizlet
OS on an R36S, then use the launcher to run native apps and games. A gizlet is a
native app or game you can publish in GitHub Releases and share by its repository
link.

[Visit gizlet.io](https://gizlet.io/) · [Browse apps and games](https://gizlet.io/explore) · [Install Gizlet OS](https://gizlet.io/install)

## Projects

| Project | What it does |
| --- | --- |
| [Gizlet](https://github.com/gizlet/gizlet) | The website, app registry, downloads, and accounts. |
| [Gizlet OS](https://github.com/gizlet/os) | The Linux base system, launcher, and SD card images for supported handhelds. |
| [Gizlet Browser](https://github.com/gizlet/browser) | A WebKit browser designed for handheld controls. |
| [Little Prince](https://github.com/gizlet/little-prince) | A 3D game about walking around a tiny planet. |
| [Overeaten](https://github.com/gizlet/overeaten) | A game about taking plates off a sushi conveyor belt and eating as much as you can before closing. |

## Build a gizlet

Use a language and UI toolkit that can build a native Linux executable for the
target handheld. The [package format](https://github.com/gizlet/gizlet/blob/main/docs/gizlet-toml.md)
explains how to describe your project with `gizlet.toml` and package it as a
`.gzl` file for GitHub Releases.
